# 01~02. 소개 및 일반적인 기술사항

## 1. 소개

### 1.1 SRS의 목적
본 문서는 Mermaid의 텍스트 기반 다이어그램 작성 방식과 UMLet의 GUI 편집·상세 표현력을 결합한 다이어그램 도구(가칭 **UniDia**)의 요구사항을 정의한다. 특히 기존 Mermaid의 한계(크기 조절 시 폰트 깨짐, 화살표 경로 고정, 인쇄·논문용 품질 부족)를 보완하는 데 중점을 둔다.

### 1.2 제품의 범위
웹 브라우저 기반의 다이어그램 편집기. 코드로 큰 그림을 빠르게 그리고, GUI로 세부 사항을 UMLet 수준으로 정교하게 다듬을 수 있다. 논문 삽입용 등 고품질 출력이 필요한 사용자를 주요 대상으로 한다.

### 1.3 정의, 동의어, 약어

| 용어 | 설명 |
| --- | --- |
| UML | Unified Modeling Language |
| Mermaid | 텍스트 기반으로 다이어그램을 자동 렌더링하는 오픈소스 도구 |
| UMLet | GUI 기반 UML 다이어그램 편집기 |
| 양방향 동기화 | 코드 편집 시 GUI가, GUI 편집 시 코드가 자동 갱신되는 기능 |
| 마그네틱 커넥터 | 노드를 이동해도 연결된 엣지(화살표)가 자동으로 따라와 붙는 기능 |

### 1.4 참조문서
Mermaid 공식 문서, UMLet 공식 문서, IEEE 830 SRS 표준

### 1.5 개요
2장은 제품의 전반적인 기술사항, 3장은 상세 기능·비기능 요구를 기술한다.

## 2. 일반적인 기술사항

### 2.1 제품의 개관
기존에는 "빠른 코드 작성"(Mermaid)과 "정교한 수동 편집"(UMLet) 중 하나만 잘한다. UniDia는 이 두 도구의 장점을 하나로 합쳐 이 문제를 해결한다.

### 2.2 제품의 기능 (개요)
- 텍스트 코드 → 다이어그램 실시간 렌더링
- GUI 드래그앤드롭 수동 편집
- 코드 ↔ GUI 양방향 실시간 동기화
- 노드-엣지 마그네틱 기능
- 엣지(화살표) 경로 수동 조정
- 스케일 안정형 폰트 렌더링
- UML 표준 다이어그램 유형 지원 (클래스, 시퀀스)
- 출판·인쇄용 내보내기 (고해상도 PNG/JPG, 흑백 인쇄 시에도 4가지 이상 색상 구분)
- Mermaid 기반 UI/UX + 코드 타이핑 편집 영역 항상 포함

### 2.3 사용자 특성

| 사용자 그룹 | 특성 |
| --- | --- |
| 개발자 | 코드로 빠르게 큰 구조를 그리는 것을 선호 |
| 연구자/논문 작성자 | 출판 품질의 정교한 다이어그램 필요 |
| 기획자/디자이너 | GUI 기반 세부 편집 선호 |

### 2.4 제약사항
- 웹 브라우저 기반, 오프라인 미지원
- Mermaid 문법 기반이므로 미지원 표기법은 우선 제외
- 코드·GUI 편집 항상 공존 (코드 없는 GUI 전용 모드 미제공)

### 2.5 가정 및 의존성
- 최신 브라우저 가정
- Mermaid.js 엔진에 의존, 추가 기능은 별도 레이어로 구현
