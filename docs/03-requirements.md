# 03. 상세한 요구사항

## 3.1 외부 인터페이스
- 웹 UI: 코드 타이핑 편집 영역 + GUI 캔버스 편집 영역 (동시 표시)
- 내보내기 인터페이스: JPG/PNG/Mermaid 코드 다운로드 (※ REQ-08은 PNG/JPG만 정의 — [open-issues](open-issues.md) 참고)

## 3.3 성능요구
- 코드 입력 후 렌더링 지연은 1초 이내
- 노드 30개 규모에서도 드래그·마그네틱 재배치가 끊김 없이 동작 (60fps 기준)

## 3.4 논리 데이터베이스 요구
- 다이어그램은 JSON(노드·엣지 좌표, 스타일 포함)으로 저장되며, Mermaid 코드로 상호 변환 가능해야 한다
- 엣지의 수동 경로 포인트도 별도 좌표 데이터로 저장되어야 한다

## 3.5 설계 제약사항
- 렌더링 엔진은 Mermaid.js 기반, 마그네틱·경로·폰트 스케일링은 별도 오버레이로 구현
- GUI 편집 결과는 반드시 적법한 Mermaid 문법으로 직렬화 가능해야 함

## 3.6 소프트웨어 시스템 속성
- 사용성: 코드/GUI 중 하나만 알아도 완성 가능
- 출력 품질: 논문 심사에서 지적받지 않을 해상도·가독성이 핵심 목표
- 유지보수성: 새 다이어그램 유형 추가가 플러그인 형태로 가능해야 함
