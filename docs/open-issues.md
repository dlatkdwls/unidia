## UI 설계 단계 원칙 (예정)
UI 설계 시 사용자를 유도하거나 선택을 방해하는 설계(다크 패턴)를 피한다. 검토 기준 세 가지:
1. **사실인가?** 표시하는 정보에 실제 근거가 있는가
2. **알 수 있는가?** 결정 전에 조건과 결과를 읽을 수 있는가
3. **거절 가능한가?** 취소·되돌리기가 발견 가능하고 실행 가능한가

적용 예: 파괴적 동작은 Undo 제공, 내보내기 옵션 기본값은 끔, 취소·닫기 문구는 중립적으로, 설정 문구는 긍정형으로, 버튼 라벨은 실제 동작과 일치.
